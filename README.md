# cupart ☕

AI-генератор дизайна для кофейных стаканов. Опиши идею — сервис соберёт
уникальный дизайн, покажет его на стакане в live-превью и отдаст чёткий файл для
печати.

**Стек:** Next.js 16 · React 19 · Tailwind CSS 4 · Drizzle ORM · PostgreSQL

---

## Возможности

- **Встроенный генератор** дизайна (canvas, без внешних AI-API) — 8 паттернов и
  палитр, автоматический подбор читаемого текста.
- **Live-превью** — дизайн оборачивается вокруг реалистичного стакана (3/4 ракурс,
  крышка, тени, кривизна).
- **Экспорт в высоком разрешении** — до 3840px (готово к 300 DPI), чёткие линии.
- **Аккаунты и тарифы** — регистрация, лимиты генераций, история.
- **Тарифы:** «Проба» (5 генераций) и «Кофейня» (100 генераций/мес).

## Локальный запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000

Локально база данных не нужна: приложение автоматически использует **PGlite**
(Postgres в WASM, файл `./.pglite`). Тот же код работает с настоящим Postgres на
проде.

## Деплой на Vercel (бесплатно)

> ⚠️ На Vercel файловая система только для чтения, поэтому PGlite там не работает —
> нужен внешний Postgres. Бесплатно подойдёт **Neon** или **Vercel Postgres**.

1. Залей проект в GitHub-репозиторий.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → выбери репозиторий.
3. Создай бесплатную БД: в проекте Vercel → вкладка **Storage → Create Database →
   Postgres** (или подключи Neon). Vercel сам добавит переменную `DATABASE_URL`.
4. В **Settings → Environment Variables** добавь:
   - `DATABASE_URL` — строка подключения к Postgres (обычно уже добавлена п.3).
   - `AUTH_SECRET` — любая длинная случайная строка (для подписи сессий).
5. Нажми **Deploy**. Таблицы создаются автоматически при первом запросе.
6. Домен подключается в **Settings → Domains** (добавишь, когда будет готов).

Никаких других настроек не требуется — `next build` уже проверен и проходит.

## Переменные окружения

| Переменная     | Где нужна      | Значение                                            |
| -------------- | -------------- | --------------------------------------------------- |
| `DATABASE_URL` | Vercel (прод)  | Строка подключения к Postgres (Neon/Vercel Postgres) |
| `AUTH_SECRET`  | везде          | Случайная строка для подписи cookie-сессий          |

Локально можно оставить `DATABASE_URL` пустым — включится PGlite.
